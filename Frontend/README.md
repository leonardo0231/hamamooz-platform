# فرانت اولیه هم‌آموز

این رابط برای بررسی سریع قابلیت‌های Backend ساخته شده است و جایگزین طراحی نهایی محصول نیست. امکانات فعلی:

- ورود واقعی با JWT و Refresh خودکار توکن
- انتخاب یک شعبه یا مشاهده همه شعب مجاز
- داشبورد شاخص‌ها، گردش ارزیابی و Audit
- فهرست ثبت‌نام دانش‌آموزان و کلاس‌ها
- فهرست ارزیابی و اجرای Submit/Approve/Reject/Lock مطابق دسترسی کاربر
- مشاهده گزارش‌ها و دریافت PDF با احراز هویت
- بارگذاری XLSX و مشاهده Jobهای Import
- رابط فارسی RTL و Responsive

## اجرای توسعه

ابتدا Backend باید روی پورت ۸۰۰۰ اجرا شود:

```bash
cp .env.example .env
npm install
npm run dev
```

فرانت در `http://localhost:3000` باز می‌شود و Vite درخواست‌های `/api` را به Backend Proxy می‌کند.

## Build

```bash
npm ci
npm run build
```

خروجی در `dist/` ساخته می‌شود. در Docker، Nginx همین خروجی را سرو و مسیر `/api/` را به سرویس `web` متصل می‌کند.

توکن‌ها در این نسخه بررسی اولیه داخل `localStorage` نگهداری می‌شوند. برای نسخه Production فرانت، مهاجرت به Cookie امن HttpOnly و تکمیل سیاست CSP پیشنهاد می‌شود.
