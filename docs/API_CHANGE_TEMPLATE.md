# قالب تحویل تغییر API

این قالب برای هر Endpoint جدید یا تغییرکرده تکمیل می‌شود.

```text
Endpoint:
Method:
Operation ID:
هدف:
Roleهای مجاز:
Scope موردنیاز:
Path Parameters:
Query Parameters:
Request Body:
Success Response:
Validation Errors:
Permission Errors:
نمونه Request:
نمونه Response:
Pagination:
Async یا Sync:
وضعیت Backend:
آدرس Dev:
مالک Backend:
مالک Frontend:
Breaking Change:
```

## وضعیت‌های مجاز

```text
Draft
Contract Ready
Backend Implemented
Backend Tested
Deployed to Dev
Frontend Integrated
QA Accepted
Released
```

Frontend فقط زمانی پیاده‌سازی را شروع می‌کند که Endpoint حداقل در وضعیت `Contract Ready` باشد.
